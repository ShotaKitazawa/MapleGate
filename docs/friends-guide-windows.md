# Playing through MapleGate (Windows)

The reply to the download command in Discord already carries the points where people get stuck; this is the longer version to point someone to.

This sends your game's traffic through a server in the US west. It only runs while you ask it to, and it needs one approval each time.

## Install (once)

1. In the Discord server, type `/download-windows`. Click "Download link" in the reply (only you see it, and it works for 15 minutes) to download `MapleGate-Setup.exe`.
2. The installer is not signed, so Windows shows "Windows protected your PC". Choose **More info**, then **Run anyway**. Allow the administrator prompt.
3. A grey dot appears in the tray at the bottom right (it may be under the ^ arrow). MapleGate is also in the Start menu.
4. You will get an e-mail from AWS inviting you to set a password. Do that first.

## Play

1. Click the dot, then **Connect**. A browser opens the first time: sign in with the account from the invitation.
2. Wait. The person who runs the server gets a message and presses Approve. The menu says what it is waiting for.
3. When the dot is green and a notice says Connected, start the game.
4. When you are done, click the dot, then **Disconnect**. Please always disconnect: while you stay connected the server keeps running and counts everything you do as use.

Colours: grey, not connected; amber, signing in or waiting for approval; green, connected; red, something went wrong (the menu says what).

## If something is wrong

- Choose **Copy diagnostics** in the menu, then paste into your message to the person who runs the server. It holds no password or key.
- Red with "The request was denied": the approval was refused. Ask.
- Red with "Nobody approved in time": nobody approved in 15 minutes. Connect again and tell them.
- Red with anything else: the menu says in one sentence what to do. If it asks for Copy diagnostics, paste that to the person who runs the server; the details are in it.
- Nothing happens on Connect: choose Quit in the menu and open **MapleGate** from the Start menu. If the menu says the VPN service is not running, restart the PC once.

## Remove

Settings, Apps, MapleGate, Uninstall.
